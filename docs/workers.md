# Workers

## Notification Worker
The notification worker (NW) sends notifications to users based on certain triggers. 

- Notifications are sent for:
  - New comments on articles or submissions the user is following.
  - Replies to the user's comments.
  - New submissions from followed users.
  - System announcements.


## Email Worker
The email worker (EW) handles sending emails for various events.
- Emails are sent for:
  - Account verification.
  - Password reset requests.
  - Weekly digest of new articles and submissions.
  - Notifications for important events (e.g., new comments, replies).
